## الهدف

1. توسيع منصة "ضميج" (Damij) لتدعم أكثر من 100 لغة بشكل عملي.
2. إضافة زر **"النطق الذكي"** فوق "المرشد الذكي": عند تفعيله، يقرأ أي عنصر تمر فوقه بالماوس / تلمسه باللغة المختارة.

---

## 1. دعم 100+ لغة

البنية الحالية تحتوي بالفعل على الأساس المطلوب:
- `DamijLanguageContext` يحفظ اللغة المختارة
- `DamijAutoTranslator` يترجم نصوص الواجهة آليًا عبر edge function `damij-translate` (يستخدم Lovable AI)
- `DamijSpeechAutowire` يجبر TTS على نطق اللغة الحالية

لذلك إضافة 100+ لغة لا يحتاج كتابة 100 ملف ترجمة، بل تمديد القوائم فقط:

### التعديلات

- **`src/features/damij/i18n/types.ts`**
  - تحويل `DamijLangCode` إلى `string` مع قائمة موسّعة `DAMIJ_LANGS` تشمل +100 لغة (العربية، الإنجليزية، الإسبانية، الفرنسية، الألمانية، البرتغالية، الروسية، الصينية، اليابانية، الكورية، الهندية، الأردية، الفارسية، العبرية، التركية، الإيطالية، الهولندية، البولندية، السويدية، اليونانية، التايلندية، الفيتنامية، الإندونيسية، الماليزية، الفلبينية، السواحلية، الأمهرية، الصومالية، الكردية، الباشتو، البنغالية، التاميلية، التيلوغو، المالايالامية، الكانادا، الغوجاراتية، الماراثية، البنجابية، السنهالية، البورمية، الخميرية، اللاوية، المنغولية، الكازاخية، الأوزبكية، التركمانية، الأذرية، الجورجية، الأرمنية، الأوكرانية، الصربية، الكرواتية، البوسنية، السلوفاكية، التشيكية، المجرية، الرومانية، البلغارية، الألبانية، المقدونية، السلوفينية، الفنلندية، الإستونية، اللاتفية، الليتوانية، النرويجية، الدنماركية، الأيسلندية، الإيرلندية، الويلزية، الباسكية، الكتالانية، الغاليسية، الأفريكانس، الزولو، الكوسا، الإيغبو، اليوروبا، الهوسا، التيغرينية، الهايتية، الكيشوا، الغواراني، الإسبرانتو، اللاتينية، إلخ).
  - كل لغة تتضمن الكود ISO، الاسم الأصلي، الاسم بالإنجليزية، علم emoji، واتجاه `rtl/ltr`.

- **`src/features/damij/i18n/DamijLanguageContext.tsx`**
  - الاحتفاظ بالقواميس الثابتة الـ15 الحالية كـ "ترجمة سريعة" (zero-latency).
  - باقي اللغات تعتمد على القاموس الإنجليزي كـ fallback نصي + `DamijAutoTranslator` يقوم بترجمة كل نصوص الـ DOM فوريًا.
  - حذف العقيدة "must exist in DICTS" لتسمح بأي كود لغة.

- **`supabase/functions/damij-translate/index.ts`**
  - توسيع `LANG_NAMES` إلى نفس قائمة الـ100+ (لتسمية اللغة في prompt).
  - إن لم يوجد الكود، استخدام الكود نفسه (Lovable AI تتعرف على معظم رموز ISO).

- **`src/features/damij/i18n/useDamijSpeech.ts` و `src/components/damij/DamijSpeechAutowire.tsx`**
  - توسيع جدول `BCP47` ليغطي كل اللغات الجديدة (مع fallback ذكي: لو ما وُجد، استخدم الكود نفسه + اختيار أقرب صوت متوفر في المتصفح).

- **`src/components/damij/DamijLanguageSwitcher.tsx`**
  - شريط بحث (موجود مسبقًا) + قائمة قابلة للتمرير + تجميع حسب الحرف الأول.
  - عرض العلم + الاسم الأصلي + الاسم الإنجليزي.

> ملاحظة: جودة الترجمة و TTS تعتمد على Lovable AI (للنصوص) و Web Speech API (للصوت). الأصوات المتوفرة تختلف حسب نظام التشغيل/المتصفح، وسنختار دائمًا أقرب صوت متاح آليًا.

## 2. زر "النطق الذكي" فوق المرشد الذكي

ميزة جديدة: عند التفعيل، أي عنصر يُحوَّم فوقه (Hover) أو يُلمَس (Touch) داخل `.damij-root` يُنطَق صوتيًا بنفس اللغة المختارة.

### التعديلات

- **ملف جديد `src/components/damij/DamijHoverSpeak.tsx`**
  - مكوّن صغير يضع زر FAB دائريًا فوق زر المرشد الذكي مباشرة (نفس الزاوية).
  - أيقونة `Volume2` / `VolumeX` مع تسمية "النطق الذكي" (مترجمة).
  - حالة `enabled` محفوظة في `localStorage` (`damij_hover_speak`).
  - عند التفعيل: يربط مستمعَين عالميَّين على `.damij-root`:
    - `mouseover` (مع debounce 150ms)
    - `touchstart` للأجهزة اللمسية
  - يستخرج النص الظاهر للعنصر الأقرب الذي يحوي نصًا (button, a, h*, p, span, label, li…) ويتجاهل العناصر داخل `[data-damij-no-speak]` و `input/textarea`.
  - يستخدم `useDamijSpeech().speak(text)` لنطق النص بلغة الواجهة الحالية مباشرةً (لا حاجة لترجمة، لأن النصوص أصلًا مترجمة في الـ DOM).
  - مؤشر بصري خفيف (تظليل dashed-outline) على العنصر الذي يجري نطقه.
  - عند الإيقاف: يلغي المستمعين ويستدعي `speechSynthesis.cancel()`.

- **`src/pages/damij/DamijLayout.tsx`**
  - إضافة `<DamijHoverSpeak />` بجانب `<DamijSmartGuide />` (موضع ثابت أعلاه بـ ~70px في نفس الزاوية، يحترم اتجاه RTL/LTR).
  - تأكد أن الزر معفي من الـ Hover-speak نفسه (`data-damij-no-speak`) لتجنب نطق تسميته باستمرار.

- **ترجمة التسميات الجديدة** في `DamijDict`: إضافة `hoverSpeak: { label, on, off, hint }` في `types.ts` وتعبئتها في القواميس الثابتة الـ15؛ باقي اللغات تأخذها من المترجم الآلي.

## نقاط تقنية

- لن نلمس المنطق التشغيلي لأي قسم (Sign / Autism / ADHD / Clinical…)، فقط طبقة اللغة + زر جديد.
- التخزين المحلي يحافظ على تفضيل اللغة وحالة "النطق الذكي" بين الجلسات.
- المترجم الآلي يخزّن ترجماته في `localStorage` (موجود سابقًا)، فلا تكلفة إضافية بعد أول زيارة.
- النطق يحدث محليًا في المتصفح عبر Web Speech API (مجاني، بدون استدعاء API).
