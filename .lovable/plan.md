# خطة تحسين نظام التوحد التشخيصي والعلاجي

## 1. التشخيص: ألعاب فقط بدلاً من الأسئلة المقالية

**الوضع الحالي:** الذكاء الاصطناعي يولّد بطارية ألعاب لكنه يعتمد أحياناً على إدخال نصي/استبيان أولي مكتوب.

**التغييرات:**
- إزالة أي حقل إدخال نصي/مقالي من شاشة التشخيص (`AutismDiagnosis`، `AutismHome`).
- مرحلة "التعرف على الطفل" تتم عبر **3-4 ألعاب استكشافية قصيرة** (بدلاً من استبيان):
  - لعبة "اختر وجهك المفضّل" (تفضيلات حسية)
  - لعبة "تابع الفقاعة" (انتباه)
  - لعبة "قلّد الحركة" (تقليد)
  - لعبة "استجب لاسمك" (تواصل)
- نتائج هذه الألعاب الاستكشافية تُمرَّر كـ `initialGameSignals` إلى `autism-generate-diagnostic-games` بدلاً من `initialConcerns` النصية.
- الذكاء الاصطناعي يبني بطارية تشخيصية مخصّصة (5-7 ألعاب) بناءً على إشارات الألعاب + العمر فقط.

## 2. تكييف الألعاب حسب العمر (تشخيصية وعلاجية)

**التغييرات في `autism-generate-diagnostic-games` و edge function علاجية:**
- إضافة `ageBand` صريح: `toddler (2-4)` / `preschool (4-6)` / `child (6-9)` / `tween (9-12)` / `teen (12+)`.
- لكل قالب لعبة، تحديد `min_age` و `max_age` في `TEMPLATE_REGISTRY` وفلترة القوالب قبل إرسالها للـ AI.
- تحديث `SYSTEM` prompt ليُلزم الذكاء الاصطناعي بـ:
  - مفردات/تعليمات بمستوى عمر الطفل
  - مدة جلسة مناسبة (40 ث للصغار، حتى 180 ث للكبار)
  - صعوبة وعدد محفّزات تتناسب مع المرحلة
- نفس المنطق يُطبَّق على edge function توليد الجلسات العلاجية.

## 3. العلاج: ألعاب فقط، 5 ألعاب يومياً، جودة أعلى

**الوضع الحالي:** البرنامج العلاجي قد يحتوي عناصر نصية/تعليمات مكتوبة طويلة وعدد ألعاب غير ثابت يومياً.

**التغييرات:**
- إنشاء/تحديث edge function `autism-generate-therapy-day` لتُرجِع **5 ألعاب بالضبط** لكل يوم، كل لعبة مرتبطة بـ `template_id` من السجل.
- إزالة أي بطاقات "تأمل/قراءة/مهمة مقالية" من `AutismDayView`.
- ترقية القوالب البصرية (`templates/`):
  - رسوم متحركة أنعم (Framer Motion + spring)
  - تأثيرات صوتية إيجابية عند النجاح
  - نظام نقاط/نجوم/شارات داخل كل لعبة
  - خلفيات متدرّجة وألوان حسب نوع المهارة

## 4. إعادة تصميم البرنامج التفاعلي (الصفحة المنفصلة)

**المرجع:** الصورة المرفقة تُظهر تصميماً ضعيفاً (بطاقات مسطّحة، تباين منخفض، تكرار رتيب).

**التغييرات على `AutismProgramCalendar.tsx`:**
- **هيدر بطل (Hero):** صورة طفل/أيقونة كبيرة، اسم الطفل، شريط تقدّم دائري للأيام المكتملة.
- **بطاقات الإحصاء:** 4 بطاقات بأيقونات ملوّنة وتدرّجات (مكتمل / متوسط الأداء / متبقّي / أفضل مهارة).
- **عرض الأيام:**
  - تبويبات أسبوعية (الأسبوع 1، 2، 3...) بدلاً من قائمة 90 صف.
  - كل يوم بطاقة كبيرة بصورة مصغّرة، عنوان واضح، شارات الـ 5 ألعاب، حالة (مقفل / متاح اليوم / مكتمل).
  - اليوم الحالي مميّز بحد متوهّج وحركة نبض.
- **مخطط تقدّم:** Recharts (خط/رادار) يعرض تطوّر الطفل عبر الأسابيع حسب المهارة.
- **زر "تحميل التقرير":**
  - PDF شامل (jsPDF) فيه: بيانات الطفل، التقدّم، نتائج كل لعبة، توصيات AI، مخططات.
  - زر ثانٍ: تصدير CSV للنتائج الخام.
- ألوان من الـ design system (`hsl(var(--damij-*))`) فقط.

## 6. خارج النطاق
- لا تغييرات على بقية أقسام دامج (إشارة، بريل، حسي، إكلينيكي).
