## 2. تحسين خيار لغة الإشارة

### الوضع الحالي
- عند تفعيل لغة الإشارة من لوحة الوصول، يظهر دليل (SignLanguageGuide) كـ overlay/modal داخل نفس الصفحة
- الكاميرا (SignLanguageCamera) تتعرف على إيماءات اليد وتحولها لأوامر تحكم بالمنصة فقط (توقف، التالي، تأكيد...)
- لا توجد صفحة مستقلة لقراءة لغة الإشارة وتحويلها لكلام

### التحسين المطلوب
إنشاء صفحة مستقلة `/sign-language` تحتوي على:

- **كاميرا لقراءة لغة الإشارة**: تستخدم MediaPipe HandLandmarker لتتبع حركات اليد
- **تحويل الإشارات إلى نص عربي**: عرض النص المترجم في الوقت الفعلي
- **تحويل النص إلى كلام**: زر لنطق النص المكتشف باستخدام Web Speech API
- **سجل الإشارات**: عرض تاريخ الإشارات المكتشفة خلال الجلسة
- **قاموس مرجعي**: عرض الإشارات المدعومة مع شرحها

### التفاصيل التقنية

**صفحة لغة الإشارة الجديدة** ستتضمن:
- استخدام `@mediapipe/tasks-vision` (مثبت بالفعل) لتتبع اليد
- واجهة بتصميم متوافق مع باقي المنصة (خلفية متدرجة، Navbar، Footer)
- قسم الكاميرا مع Canvas overlay لعرض نقاط اليد
- قسم النص المكتشف مع زر تحويل لكلام عبر `window.speechSynthesis`
- قسم القاموس المرجعي من البيانات الموجودة حاليا في SignLanguageGuide
- تصميم responsive يعمل على الجوال والحاسوب
