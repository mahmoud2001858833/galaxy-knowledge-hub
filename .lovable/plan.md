## الهدف

تحويل صفحة **"تعلّم بريل"** إلى **"قاموس بريل"** احترافي يدعم:
- ترجمة كلمة/جملة من **أي لغة من ~100 لغة → بريل** بشكل احترافي.
- **الرجوع**: من **بريل → نص** بأي لغة مختارة.
- **النطق الصوتي** للكلمة بلغتها وللناتج بعد فك الترميز.
- عرض **خلايا بريل بصرية** (نقاط) إلى جانب الرمز Unicode.
- **تاريخ بحث محلي** + **مفضلات** + نسخ سريع.

## الواجهة (Dictionary UI)

```
┌─────────────────────────────────────────────────┐
│  📖 قاموس بريل العالمي                            │
│  يدعم ~100 لغة + المستوى 1 و 2 + نطق صوتي         │
├─────────────────────────────────────────────────┤
│  [🔄 اتجاه الترجمة]   نص → بريل   |   بريل → نص   │
│  [🌐 اللغة ▾] [📚 المستوى: 1 / 2 ]               │
├─────────────────────────────────────────────────┤
│  حقل الإدخال (كلمة/جملة)         [🎤] [🔊] [🔍]  │
├─────────────────────────────────────────────────┤
│  الناتج:                                         │
│   ⠁⠃⠞   ←  بخط بريل كبير                          │
│   تمثيل بصري بالنقاط (خلية لكل حرف)              │
│   [📋 نسخ] [🔊 استماع] [⭐ حفظ في المفضلة]        │
├─────────────────────────────────────────────────┤
│  📜 آخر عمليات البحث      ⭐ المفضلة               │
└─────────────────────────────────────────────────┘
```

العناصر الأساسية:
1. **Toggle**: نص↔بريل (سهم تبديل في المنتصف).
2. **محدّد لغة** (نفس قائمة `SPOKEN_LANGUAGES`، ~100 لغة).
3. **مستوى بريل** 1 (حرفي) / 2 (اختزالي).
4. **حقل إدخال واحد** ذكي حسب الاتجاه (نص عادي أو خلايا ⠁⠃⠉).
5. **زر مايكروفون** (Web Speech API) لإدخال الكلمة صوتياً بلغة الواجهة.
6. **زر نطق** للناتج وللمدخل (SpeechSynthesis بلغة المستخدم).
7. **عرض نقطي**: لكل خلية بريل، نرسم 6 نقاط مثل المكوّن الحالي `BrailleCellDisplay`.
8. **تاريخ + مفضلة** عبر `localStorage` فقط (لا حاجة لقاعدة بيانات).

## آلية الترجمة

نستخدم edge function الموجود **`braille-convert`** بدون أي تغيير في السكيمة:
- نص → بريل: `mode: "convert"` مع `grade` و `langCode/langName` (مدعوم أصلاً).
- بريل → نص: `mode: "reverse"` (تمت إضافته للتو).

النطق الصوتي يتم **في المتصفح فقط** عبر `window.speechSynthesis` مع تمرير `langCode` (لا يحتاج صلاحيات/أسرار).

التعرف الصوتي للإدخال عبر `webkitSpeechRecognition` متى كان متاحاً (مع رسالة احتياط).
