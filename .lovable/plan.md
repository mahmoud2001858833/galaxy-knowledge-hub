
# خطة ميزة "الامتحان" - ماسح الامتحانات الذكي

## الفكرة
إضافة خيار "الامتحان" في شريط التنقل العلوي (Navbar) يفتح صفحة مخصصة لمسح أوراق الامتحانات عبر الكاميرا، استخراج الأسئلة تلقائيا بالذكاء الاصطناعي، ثم عرض الإجابات مع شرح مفصل لكل سؤال.

## آلية العمل

1. الضغط على "الامتحان" في الـ Navbar يفتح صفحة `/exam-scanner`
2. تُفتح الكاميرا فورا لتصوير ورقة الامتحان
3. يمكن تصوير عدة صفحات (مثلا 4 صفحات) واحدة تلو الأخرى
4. عند الضغط على "تم"، يتم إرسال جميع الصور إلى الذكاء الاصطناعي (Google Gemini) لاستخراج الأسئلة
5. تُعرض الأسئلة مع الإجابات الصحيحة بجانبها
6. تحت كل سؤال زر "تعرف لماذا؟" يعرض شرحا مفصلا للإجابة

## الملفات المتأثرة

| الملف | التغيير |
|-------|---------|
| `src/pages/ExamScannerPage.tsx` | صفحة جديدة - واجهة المسح والتحليل |
| `supabase/functions/exam-analyzer/index.ts` | Edge function جديدة لتحليل صور الامتحان بالذكاء الاصطناعي |
| `src/App.tsx` | إضافة route جديد `/exam-scanner` |
| `src/components/Navbar.tsx` | إضافة رابط "الامتحان" في شريط التنقل (Desktop + Mobile) |

## التفاصيل التقنية

### 1. صفحة ExamScannerPage.tsx
- **المرحلة الأولى - التصوير**: فتح الكاميرا تلقائيا عند دخول الصفحة، زر التقاط، عداد للصفحات الملتقطة، معاينة مصغرة للصور، وزر "تم" للانتقال للتحليل
- **المرحلة الثانية - التحليل**: شاشة تحميل أثناء تحليل الصور بالذكاء الاصطناعي
- **المرحلة الثالثة - النتائج**: عرض كل سؤال مستخرج مع الإجابة الصحيحة، وزر "تعرف لماذا؟" يعرض شرحا قابلا للطي (Collapsible)
- **تصميم متوافق مع الجوال**: كاميرا بملء الشاشة على الهاتف، أزرار كبيرة سهلة اللمس
- تحويل الصور إلى Base64 قبل الإرسال

### 2. Edge Function: exam-analyzer
- تستقبل مصفوفة من الصور (Base64)
- ترسلها إلى Google Gemini API (مفتاح API المقدم: `AIzaSyABqat_3N9lZNurPyi90pb94e88ihh2oUA`)
- يُطلب من الـ AI استخراج جميع الأسئلة من الصور، تحديد الإجابة الصحيحة لكل سؤال، وكتابة شرح مفصل
- النتائج تُرجع كـ JSON منظم

### 3. تحديث Navbar
- إضافة رابط "الامتحان" بعد "الألغاز" في قائمة التنقل للـ Desktop
- إضافة نفس الرابط في القائمة الجانبية للموبايل

### 4. تحديث App.tsx
- إضافة `import ExamScannerPage` و route `/exam-scanner`

## تجربة المستخدم على الجوال
- الكاميرا تفتح بوضع ملء الشاشة مع إطار توجيهي لوضع الورقة
- أزرار كبيرة وواضحة (التقاط / التالي / تم)
- شريط سفلي يعرض الصور المصغرة الملتقطة مع إمكانية حذف أي صورة
- عرض النتائج بتصميم بطاقات متجاوب
