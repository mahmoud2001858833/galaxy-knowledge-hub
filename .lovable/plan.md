
# خطة إضافة 20 تجربة تعليمية تفاعلية جديدة

## الوضع الحالي
المنصة تحتوي حالياً على **29 تجربة** مبنية بالكامل. كل تجربة عبارة عن صفحة React مستقلة تستخدم Canvas API للرسم مع أدوات تحكم تفاعلية.

## آلية البناء لكل تجربة

كل تجربة ستُبنى بنفس المعمارية الموجودة:

1. **صفحة React مستقلة** (400-900 سطر) تحتوي على:
   - Canvas API للرسم والأنيميشن بدقة عالية
   - أدوات تحكم تفاعلية (Sliders, Buttons, Tabs)
   - معلومات علمية ومعادلات (InfoSection)
   - اختبار قصير (QuizSection)
   - تصميم متجاوب مع خلفية متحركة

2. **تسجيل في App.tsx** كمسار جديد مع AuthGuard

3. **إضافة للقائمة في ExperimentsSection.tsx** مع أيقونة ولون وميزات

## التفاصيل التقنية

- كل تجربة ملف واحد مستقل في `src/pages/`
- تستخدم Canvas 2D API للرسم مع requestAnimationFrame
- تستخدم مكونات SimulationLayout المشتركة
- واجهة عربية RTL مع تصميم متوافق مع باقي التجارب
- ألوان وأيقونات فريدة لكل تجربة
- أزرار تشغيل/إيقاف/إعادة تعيين
- تبويبات لأنواع المحاكاة الفرعية داخل كل تجربة
