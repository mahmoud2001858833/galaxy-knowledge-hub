## الهدف
ترجمة جميع إشارات قاموس ArSL (3,341 إشارة) إلى كل اللغات الـ14 المتاحة في المنصة (en, fr, es, de, tr, ur, hi, fa, he, ru, zh, ja, ko, pt) مع عرض احترافي وسلس في كل ميزات لغة الإشارة.

## الاستراتيجية
- **توليد مُسبَق**: استخدام Lovable AI Gateway (gemini-3-flash) لترجمة القاموس بالكامل عبر سكربت دفعات (batches من 50 كلمة) وحفظ النتائج كملفات JSON ثابتة محلياً.
- **تخزين**: ملف JSON واحد لكل لغة في `src/features/sign-language/dictionary/translations/{lang}.json` يحتوي خريطة `{ arabicWord: translation }`.
- **تحميل ذكي (Lazy load)**: استيراد ديناميكي حسب لغة الواجهة الحالية حتى لا يتضخم البنادل الأولي — كل لغة تُحمَّل فقط عند الحاجة.

## ما سيتم بناؤه

### 1. سكربت توليد الترجمات (`/tmp/translateArSL.mjs`)
- يقرأ `arslDictionary.ts` ويستخرج 3,341 كلمة فريدة.
- لكل لغة من 14 لغة:
  - يقسّم الكلمات إلى دفعات من 50.
  - يستدعي Lovable AI مع prompt احترافي: "ترجم هذه الكلمات العربية إلى {اللغة} مع الحفاظ على الدقة اللغوية والثقافية، أرجع JSON خالص".
  - يدمج النتائج ويحفظها في `src/features/sign-language/dictionary/translations/{lang}.json`.
- يدعم الاستئناف (resume) إذا انقطع، ويتعامل مع 429/402.

### 2. وحدة الترجمة (`src/features/sign-language/dictionary/translations/index.ts`)
- `loadSignTranslations(lang)`: تحميل ديناميكي + كاش في الذاكرة.
- `translateSign(arabicWord, lang)`: إرجاع الترجمة أو الكلمة الأصلية كاحتياط.
- `useSignTranslation(lang)`: hook يعرض حالة التحميل + خريطة الترجمات.

### 3. تحديث الميزات الثلاث

**أ. معرض القاموس داخل `YouTubeSignTranslator.tsx`**
- إظهار الترجمة بلغة الواجهة الحالية تحت كل بطاقة إشارة بخط أصغر وبلون `text-muted-foreground`.
- شارة صغيرة تُظهر رمز اللغة الحالية.

**ب. مترجم النص-إلى-إشارة (`SignTranslator.tsx`)**
- إظهار الترجمة بجانب gloss العربي في كل بطاقة إشارة في التتابع.

**ج. مترجم يوتيوب (timeline + الإشارات المتزامنة)**
- إضافة سطر ترجمة تحت اسم الإشارة الحالية بلغة الواجهة لتعزيز التزامن متعدد اللغات.

### 4. ربط بسياق اللغة
- استخدام `DamijLanguageContext` لمعرفة اللغة الحالية تلقائياً.
- إضافة مُبدّل بصري صغير في معرض القاموس لاختبار لغات أخرى دون تغيير لغة الواجهة الكاملة.

## تفاصيل تقنية

### بنية ملف الترجمة (مثال en.json)
```json
{
  "مرحباً": "Hello",
  "أهلاً": "Welcome",
  "السلام عليكم": "Peace be upon you",
  "أب": "Father",
  ...
}
```

### الأرقام التقديرية
- 3,341 كلمة × 14 لغة = 46,774 ترجمة.
- 50 كلمة/طلب → ~67 طلب/لغة → ~938 طلب إجمالاً.
- مع تأخير 1.5 ثانية بين الطلبات: ~25 دقيقة إجمالي توليد (يعمل مرة واحدة فقط).
- حجم كل ملف JSON: ~120-250KB → إجمالي ~2.5MB، يُحمَّل واحد فقط في كل مرة.

### استراتيجية الجودة
- نظام prompt صريح: "أنت مترجم محترف متخصص في معاجم لغة الإشارة. الدقة اللغوية والمعنى الإشاري لهما الأولوية".
- معالجة الكلمات الخاصة (الأرقام، الألوان، أفعال متعددة الصيغ) بقوالب موحدة.
- Pass ثاني للتحقق على عينة 5% عشوائية قبل الاعتماد.

### معالجة الأخطاء
- 429 → backoff تلقائي + تأخير أطول.
- 402 → إيقاف وعرض رسالة للمستخدم.
- كلمة فاشلة → إعادة محاولة فردية، ثم تعيين قيمة فارغة (يستخدم العربي كاحتياط).

## ملاحظات
- العملية كلها تتم مرة واحدة عند التنفيذ، ثم الملفات تصبح ثابتة في المستودع.
- لا تغييرات على البنية الخلفية أو قاعدة البيانات.
- متوافق تماماً مع تطبيق Capacitor (كل شيء offline-first بعد التحميل).
