# خطة التحويل الشامل للتجارب العلمية إلى ثلاثية الأبعاد (3D)

## الوضع الحالي
- **49 تجربة** علمية موجودة في المنصة (فيزياء، كيمياء، أحياء، فلك، هندسة، رياضيات).
- **معظمها ثنائي الأبعاد**: مرسومة بـ Canvas 2D أو SVG أو حركات CSS.
- **3D فعلي موجود فقط في**: التفاعلات الكيميائية (جزئياً)، المجموعة الشمسية 3D، ومشاهد تسويقية.
- الحزم اللازمة مثبتة بالفعل: `three@0.170`, `@react-three/fiber@8`, `@react-three/drei@9`.

## الهدف
تحويل **كل** التجارب إلى بيئة ثلاثية الأبعاد تفاعلية حقيقية (دوران، تقريب، تفكيك، قياس)، مع رفع القيمة التعليمية: أهداف تعلّم، خطوات موجّهة، قياسات حية، وتقييم.

---

## المعمارية الموحّدة (الأساس قبل أي تحويل)

إنشاء طبقة مشتركة `src/components/sim3d/` تُستخدم في كل التجارب:

| المكوّن | الوظيفة |
|---|---|
| `SimCanvas` | غلاف Canvas موحّد: إضاءة، ظلال، بيئة، خلفية، أداء تلقائي |
| `SimControls` | OrbitControls + أزرار (إعادة ضبط الكاميرا، زوايا جاهزة: أمامي/علوي/مقطع) |
| `SimHUD` | لوحة قياسات حية RTL فوق المشهد (سرعة، حرارة، جهد، تركيز…) |
| `SimStage` | أرضية/شبكة قياس + محاور + مسطرة ثلاثية الأبعاد |
| `SimLabel3D` | تسميات عربية داخل المشهد (Html من drei) بدون كسر الاتجاه |
| `SimQualityGate` | كشف قدرة الجهاز → جودة عالية/متوسطة/منخفضة تلقائياً + بديل 2D عند فشل WebGL |
| `SimLessonShell` | الهيكل الموحّد للصفحة: مشهد + تحكّم + شرح + خطوات + اختبار |

**قواعد ثابتة:** كل الألوان من رموز التصميم في `index.css` (ممنوع ألوان مباشرة)، RTL كامل، تحميل كسول `React.lazy` لكل مشهد 3D، وإيقاف الحلقة عند إخفاء التبويب.

---

## نموذج "التجربة المفيدة" (يُطبَّق على كل تجربة)

كل تجربة بعد التحويل تحتوي على:
1. **هدف تعلّمي** واضح + المفاهيم المرتبطة بالمنهج.
2. **مشهد 3D تفاعلي**: سحب الأجسام، تدوير، تكبير، مقاطع عرضية.
3. **متغيّرات قابلة للتحكم** (منزلقات) تؤثر فورياً على الفيزياء/الكيمياء الحقيقية لا على الرسم فقط.
4. **قراءات حية + رسم بياني** يتحدث لحظياً.
5. **وضع التحدي**: مهمة محددة ("اجعل الجسم يصل 40 م") مع تحقق آلي.
6. **اختبار قصير** (3–5 أسئلة) مرتبط بما جرّبه الطالب.
7. **دفتر التجربة**: حفظ القراءات وتصديرها.

## مراحل التنفيذ

### المرحلة 0 — الأساس
بناء طبقة `sim3d` كاملة + صفحة اختبار داخلية + ضبط الأداء والبديل عند غياب WebGL.

### المرحلة 1 — الفيزياء الميكانيكية (تجربة مرجعية)
`ProjectileMotion`, `CircularMotion`, `FluidMechanics`, `Thermodynamics`, `MechanicalEngineering`, `RocketScience`.
تُبنى **قذف المقذوفات** أولاً كنموذج مرجعي كامل يُنسخ منطقه لبقية التجارب.

### المرحلة 2 — الكهرباء والمغناطيسية والضوء
`CircuitBuilder` (لوح توصيل 3D)، `ElectromagnetismLab` (خطوط مجال 3D)، `StaticElectricity`، `OpticsLab` و`AdvancedOptics` (أشعة ضوء حقيقية في الفراغ)، `InterferenceDiffraction`، `WavesAndSound`، `ElectromagneticWaves`، `DigitalElectronics`.

### المرحلة 3 — الكيمياء
`ChemicalReactions` (استكمال)، `OrganicChemistry` (مُحرِّر جزيئات 3D)، `Electrochemistry` (خلية جلفانية مجسّمة)، `AnalyticalChemistry` (سحّاحة ومعايرة)، `AcidsBases`، `StatesOfMatter` (جسيمات 3D)، `ChemicalKinetics`.

### المرحلة 4 — الأحياء
`LivingCell` و`CellDivision` (عضيّات مجسّمة قابلة للتشريح)، `HumanBody` (طبقات: هيكل/عضلات/دوران)، `MolecularBiology` (لولب DNA 3D)، `GeneticsLab`، `ImmuneSystem`، `Photosynthesis`، `Ecosystem`، `Evolution`.

### المرحلة 5 — الذرّية والنووية والكمّية والفلك
`BuildAtom`، `NuclearReactions`، `AdvancedNuclear`، `NuclearApplications`، `QuantumMechanics` (سحابات احتمال 3D)، `PlasmaPhysics`، `LHC` (تحسين)، `AdvancedAstronomy`، `SolarSystem` (دمج مع نسخة 3D الموجودة)، `SpecialRelativity`، `Blackbody`.

### المرحلة 6 — الرياضيات والمواد والروبوتات وعلوم الأرض
`SpatialGeometry`، `Probability`، `FourierSeries` (أسطح 3D)، `MaterialsScience` (بلورات وشبكات)، `Robotics` (ذراع مفصلية 3D)، `EarthSciences` (كرة أرضية وطبقات).

### المرحلة 7 — الصقل النهائي
تحسين الأداء على الهواتف، دعم اللمس، إمكانية الوصول (تعليق صوتي عربي، تباين عالٍ)، تدقيق علمي لكل معادلة، وتحديث بطاقات صفحة التجارب بمعاينات جديدة.

## ملاحظات تقنية
- سيتم استخدام هندسة مُولّدة برمجياً (Geometry) بدل ملفات نماذج ثقيلة، للحفاظ على سرعة التحميل.
- كل مشهد داخل `Suspense` + `lazy`، فلا تتأثر سرعة بقية المنصة.
- المعادلات تُعزل في `src/lib/sim-physics/` ليمكن اختبارها بمعزل عن الرسم.
- لا يتم تعديل مسارات التوجيه أو تصميم النسخة العامة بما يكسر تطبيق أندرويد.

## طريقة العمل المقترحة
ننفّذ **مرحلة واحدة في كل دفعة** وتراجعها، بدءاً بالمرحلة 0 + المرحلة 1 معاً (الأساس + التجربة المرجعية) لتقييم الشكل والأداء قبل توسيعه على الـ49 تجربة.
