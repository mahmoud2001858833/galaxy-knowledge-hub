## التحديثات على صفحة الرسومات التكتيلية للطباعة

### 1. تحويل المثال إلى Placeholder + صندوق "اقتراحات" (5 لكل نوع)

- إفراغ الحقل النصي عند فتح الصفحة وتحويل المثال الحالي إلى `placeholder` فقط.
- إنشاء قاموس اقتراحات داخل الملف (مثلاً `SUGGESTIONS: Record<categoryId, string[]>`) بحيث لكل نوع 5 اقتراحات مختلفة تمامًا:
  - **شكل هندسي**: مثلث متساوي الأضلاع، مكعب ثلاثي الأبعاد، دائرة بأنصاف أقطار وزوايا، شبه منحرف بقياسات، مضلع سداسي منتظم.
  - **رسم بياني**: دالة جيب الزاوية، خط مستقيم بميل موجب، أعمدة بيانية لدرجات صف، دالة تربيعية، دائرة نسب مئوية.
  - **خريطة جغرافية**: خريطة الأردن بالمحافظات، الوطن العربي، قارة أفريقيا، خريطة العالم المبسطة، مدينة عمان وأحياؤها.
  - **جزيء كيميائي**: H2O، CO2، CH4 (ميثان)، NH3 (نشادر)، C6H6 (بنزين).
  - **رسم بيولوجي**: الخلية النباتية، القلب البشري، الجهاز الهضمي، ورقة نبات بعروقها، الجهاز التنفسي.
  - **أخرى**: شعار بسيط، سهم اتجاهي، سلّم، ساعة تناظرية، علم الأردن.
- يظهر صندوق صغير أعلى/تحت المربع النصي بعنوان "اقتراحات" يعرض الخمسة كأزرار قابلة للنقر — الضغط على اقتراح يعبّئ النص في حقل الإدخال.
- تتغير الاقتراحات تلقائيًا عند تغيير الفئة المختارة.

### 2. توسيع نتيجة "وصف رسم تكتيلي"

في تبويب **describe**:

- إضافة عرض **الوصف بلغة الإشارة**: قائمة كلمات مفتاحية + عرض رسوم إشارة باستخدام مكوّن `ParametricHand` / `HandSignCard` الموجود في `src/features/sign-language` (الترجمة لعربية الإشارة كافتراضي).
- إضافة محدد لغة (`<select>`) فيه ~100 لغة — عند تغيير اللغة يُعاد طلب ترجمة الوصف والسرد عبر edge function (Gemini)، وتُحفظ النسخة الأصلية بالعربية.
- زر "استمع" يستخدم لغة الترجمة الحالية تلقائيًا.

### 3. تعديلات Edge Function `braille-tactile-generate`

- إضافة `mode: "translate"` يستقبل `{ text, target_lang }` ويرجع الترجمة عبر Lovable AI Gateway (Gemini 2.5 Flash) — لا داعي لمفتاح خارجي لأن `LOVABLE_API_KEY` متاح أصلاً ويغطي 100+ لغة باحترافية.
- في وضع `describe` نضيف للحقول الراجعة: `sign_keywords: string[]` (كلمات مفتاحية قابلة للترجمة بالإشارة).

### 4. ملاحظة بخصوص مفتاح Google API الذي أرسلته

- المنصة تستعمل **بوابة Lovable AI** للوصول إلى Gemini بنفس الجودة، وبدون الحاجة لمفتاحك الشخصي.
- نشر مفتاحك في الدردشة يُعتبر تسريبًا — يُستحسن **إبطاله من Google Cloud Console فورًا**.
- إن أردت استخدام مفتاحك الخاص رغم ذلك، أضفه عبر أداة الأسرار باسم `GEMINI_API_KEY` ولن يظهر في الكود.

### الملفات المتأثرة

- `src/pages/damij/braille/TactileGraphics.tsx` — Placeholder، صندوق الاقتراحات، محدد اللغة، عرض لغة الإشارة.
- `src/features/braille/tactile/tactileTypes.ts` — إضافة `sign_keywords` لـ `DescribeResult`.
- `supabase/functions/braille-tactile-generate/index.ts` — وضع `translate` + إخراج `sign_keywords`.

### أسئلة قبل التنفيذ

1. هل تريد أن تشمل الاقتراحات الفئات الست جميعًا (هندسي، بياني، خريطة، جزيء، بيولوجي، أخرى)؟
2. هل لغة الإشارة المطلوبة هي **عربية الإشارة الموحّدة** فقط، أم نضيف ASL/BSL لاحقًا؟
3. هل توافق على استخدام Lovable AI (مجاني/مضمّن) بدلًا من مفتاحك الشخصي للترجمة؟
