
# خطة إعادة بناء فيديو دامج (V3)

## المبادئ الأساسية
- **بدون أي تعليق صوتي** — الصوت = موسيقى سينمائية هادئة + مؤثرات انتقالية (whoosh / soft click / chime) متزامنة مع كل ظهور عنصر.
- **مدة كل مشهد ≤ 5 ثوان** (150 إطار @ 30fps). إجمالي 36 مشهد ≈ 3 دقائق (180s / 5400 frame).
- **الأرقام بالإنجليزية** (`15 / 30 / 1,200 / 120 / $150,000 / 50,000`) بخط Inter / Manrope.
- **تايبوغرافيا**: عنوان واحد كبير + 2-3 نقاط مختصرة لكل مشهد. Cairo Bold للعربي. هوامش واسعة، لا تداخل، لا نص speaker تحت.
- **حذف شريط الـ Speaker Notes** الأسود نهائياً (هو سبب التغطية).

## التفاصيل التقنية

### الموسيقى والمؤثرات
- موسيقى خلفية واحدة `bg-music.mp3` بحجم `0.25` على كامل المدة.
- 5 مؤثرات SFX خفيفة:
  - `whoosh.mp3` — انتقالات بين الأقسام (مشاهد 1،10،14،19،24،29)
  - `chime.mp3` — كشف الأرقام الكبيرة (15، 30، 1200، 150K، …)
  - `tick.mp3` — ظهور النقاط الفرعية
- توليد المؤثرات عبر ElevenLabs SFX (5 ملفات قصيرة <2s) وتشغيلها بـ `<Audio startFrom>` على فريمات محددة.

### التايبوغرافيا والتخطيط
- **عربي**: Cairo (900 / 700 / 400) فقط — حذف Amiri لتجنّب التداخل.
- **إنجليزي/أرقام**: Manrope (800 / 500).
- Layout موحّد:
  ```

  │                             │
  ```

- **حذف صندوق Speaker Notes الأسود** نهائياً.
- مسافة `padding: 90px` حول المحتوى لمنع أي تغطية.
- progress bar علوي رفيع (2px فقط) باللون الذهبي.

### الحركات الانتقالية
- بين كل مشهدين: `fade + soft scale (1.02→1)` لمدة 12 فريم — موحّد.
- داخل المشهد: عناصر تدخل بـ `spring({damping:18, stiffness:120})` مع stagger 6 فريم.
- الأرقام الكبيرة: count-up animation من 0 للقيمة النهائية على 25 فريم + chime.
- الصور: Ken Burns خفيف `scale 1.05 → 1.12` على 150 فريم.
