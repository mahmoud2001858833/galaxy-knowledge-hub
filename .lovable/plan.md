## نظام "عين الأعمى" — مرشد بصري صوتي للمكفوفين

### الفكرة
صفحة جديدة داخل قسم دامج (تحت الكفيف/الحسّي) تفتح الكاميرا الخلفية للهاتف، تحلّل المشهد بالذكاء الاصطناعي، وتُرشد المستخدم صوتياً بالعربية ("امشِ للأمام، انتبه عقبة على اليسار، التف يميناً قليلاً..."). مع وضع اختياري للملاحة إلى وجهة محددة عبر GPS.

### تجربة المستخدم (3 شاشات)
1. **الشاشة الرئيسية** — زر كبير واحد "افتح عيني" + زر "اذهب إلى مكان" (اختياري). كل شيء قابل للنقر بالكامل ومنطوق تلقائياً عند الفتح.
2. **وضع الكاميرا والإرشاد** — كاميرا خلفية بملء الشاشة + شريط حالة صوتي + زر إيقاف كبير. كل 2-3 ثواني يلتقط إطار → يحلله → ينطق التعليمات.
3. **وضع الملاحة (اختياري)** — يدخل الوجهة بالصوت ("اذهب إلى مدرسة عنبة") → GPS + Geolocation API + تعليمات اتجاه مدمجة مع تحذيرات الكاميرا.

### المكوّنات

```text
src/pages/damij/blind-eye/
  ├── BlindEyeHome.tsx          ← الشاشة الرئيسية
  ├── BlindEyeNavigator.tsx     ← الكاميرا + التحليل + النطق
  └── useBlindEyeGuide.ts       ← منطق الالتقاط الدوري والـTTS

supabase/functions/
  └── blind-eye-vision/index.ts ← Gemini Vision: تحليل الإطار → تعليمات JSON
```

### تفاصيل تقنية (للمراجعة)
- **الكاميرا**: `getUserMedia({ video: { facingMode: 'environment' } })` — الكاميرا الخلفية.
- **حلقة التحليل**: التقاط JPEG كل ~2.5 ثانية → إرسال base64 إلى edge function → Gemini 2.5 Flash Vision مع برومبت عربي يطلب JSON موحّد:
  ```json
  { "direction": "forward|left|right|stop",
    "obstacle": "نص قصير أو null",
    "urgency": "low|medium|high",
    "spoken": "نص عربي قصير ينطق فوراً" }
  ```
- **النطق**: Web Speech API (ar-SA) — نفس آلية `useDamijSpeech` الموجودة. النطق يقاطع التعليمة السابقة عند `urgency: high`.
- **الأوامر الصوتية**: `SpeechRecognition` (مثل `useArabicSpeech.ts`) — "توقف"، "أكمل"، "أين أنا"، "اذهب إلى...".
- **الاهتزاز**: `navigator.vibrate` للتنبيهات العاجلة (عقبة قريبة).
- **الملاحة (اختياري)**: `navigator.geolocation.watchPosition` + حساب bearing/مسافة إلى الوجهة. للحصول على إحداثيات وجهة من اسم: استخدام Gemini نفسه أو OpenStreetMap Nominatim (مجاني، بدون مفتاح).
- **المفتاح**: استخدام `GEMINI_API_KEY` الموجود (بدون Lovable AI — ممنوع).

### نقاط أحتاج تأكيدك عليها قبل التنفيذ
1. **الملاحة بالـGPS إلى وجهة** — هل تريدها الآن أم نبدأ فقط بوضع "وصف الطريق أمامي" ونضيف الـGPS لاحقاً؟
2. **التردد**: تحليل كل 2.5 ثانية مناسب (توازن بين السرعة والاستهلاك)، أو تفضل أسرع/أبطأ؟
3. **الموقع داخل التطبيق**: أضعها داخل `/damij/sensory/blind-eye` كأداة جديدة في صفحة الكفيف، صح؟
