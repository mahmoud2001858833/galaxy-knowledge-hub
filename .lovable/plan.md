
# خطة تطوير التجارب الـ 20 الجديدة

## ملخص التحليل
بعد مراجعة جميع التجارب الـ 20، كل واحدة تعمل بشكل أساسي لكن تحتاج تحسينات جوهرية في الجودة البصرية، التفاعلية، والمحتوى العلمي.

---

## التحسينات المشتركة لجميع التجارب

### 1. إصلاح مشكلة Canvas Scaling
- التجارب التي تستخدم `canvas.width = 700` ثابت (الفيزياء 1-5) لا تتكيف مع حجم الشاشة
- التجارب الأخرى (6-20) تستخدم `width={600} height={400}` ثابت ايضا
- **الحل**: توحيد جميعها لتستخدم `canvas.offsetWidth * 2` مع `ctx.scale(2, 2)` للوضوح العالي (HiDPI)

### 2. إضافة أسئلة اختبار اكثر
- بعض التجارب تحتوي فقط 2-3 أسئلة
- **الحل**: رفع كل تجربة إلى 4-5 أسئلة مع شروحات تفصيلية

### 3. تحسين المعلومات العلمية
- بعض التجارب تفتقر لـ `explanation` و `facts`
- **الحل**: إضافة شرح علمي وحقائق لكل تجربة

## التفاصيل التقنية

- إصلاح Canvas responsive: استخدام `useEffect` مع `ResizeObserver` لتحديث أبعاد Canvas تلقائياً
- إضافة HiDPI support: `canvas.width = offsetWidth * devicePixelRatio`
- توحيد بنية كل تجربة مع `explanation` و`facts` و4-5 أسئلة اختبار
- تحسين الأداء: استخدام `offscreenCanvas` للرسوم المعقدة
- إضافة تأثيرات توهج (glow) وظلال متحركة لجميع العناصر
